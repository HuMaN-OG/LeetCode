## How I Approach Problems

For each problem, I try to follow this process:

1. Understand the problem and constraints.
2. Think of a brute-force solution.
3. Analyze its time and space complexity.
4. Look for a better pattern or observation.
5. Implement the optimized solution.
6. Test edge cases.
7. Review the solution later when necessary.

The goal is not just to increase the number of solved problems, but to understand the underlying patterns and improve problem-solving ability.
